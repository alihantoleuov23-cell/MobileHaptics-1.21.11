# Mobile Haptics — Minecraft 1.21.11 Fabric / Zalith Launcher 2 Plus

Клиентский мод для вибрации Android-телефона при игровых действиях. Первая версия:

- вибрация при успешном разрушении блока;
- вибрация при успешной установке блока;
- включение/выключение;
- отдельная длительность для ломания и установки;
- отдельная амплитуда для каждого события;
- тест вибрации из меню;
- клавиша `H` открывает настройки.

## Почему здесь native bridge

Zalith Launcher и TouchController используют Android-side bridge для передачи haptic-событий из Minecraft-процесса в Android. Этот проект использует тот же общий принцип: Minecraft загружает небольшой `.so`, который получает `DALVIK_APPLICATION` и обращается к Android `Vibrator` через JNI.

Это **не копия проприетарного кода Zalith** и мод не требует установки TouchController.

## Сборка без ПК

1. Создай пустой GitHub-репозиторий.
2. Распакуй этот проект и загрузи все файлы.
3. Открой вкладку **Actions**.
4. Запусти `Build Mobile Haptics`.
5. После сборки скачай artifact `mobile-haptics-1.21.11`.
6. Возьми `mobile-haptics-0.1.0.jar` и положи в `mods` профиля Fabric 1.21.11 в Zalith Launcher.

Workflow сам собирает `arm64-v8a` и `x86_64` native-библиотеки перед сборкой `.jar`.

## Важно

Это экспериментальная первая сборка. Проверить её запуск в Zalith из текущей среды невозможно, потому что среда сборки не имеет сетевого доступа к Maven/GitHub. Поэтому обязательна проверка на реальном устройстве.

Если вибрация не появится:

- проверь, что на конкретной сборке Zalith экспортируется `DALVIK_APPLICATION`;
- проверь разрешение Android на вибрацию;
- пришли crash-log / latestlog, и bridge можно будет подправить под конкретную сборку Zalith 2 Plus.
