# Сборка на телефоне через GitHub Actions

Самый простой путь без ПК — GitHub в браузере или GitHub Mobile.

1. Создай репозиторий.
2. Загрузись содержимое этой папки.
3. Перейди в **Actions** → `Build Mobile Haptics` → `Run workflow`.
4. Дождись зелёной сборки.
5. Открой run → **Artifacts** → `mobile-haptics-1.21.11`.
6. Распакуй artifact и установи `mobile-haptics-0.1.0.jar` в `mods`.
